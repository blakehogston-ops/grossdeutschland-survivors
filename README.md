# Grossdeutschland: Eastern Front

A stylized browser arcade survival game (Vampire Survivors-style) set on the Eastern Front, winter 1942-43. Play a Panzergrenadier of the Grossdeutschland Division holding the line against Red Army waves. Weapons: Kar98k, Gewehr 43, MP 40, MG 42, Stielhandgranate, Panzerfaust, Flammenwerfer, Nebelwerfer / leFH 18 artillery, and StuG III / Panzer III / IV / Tiger I support. Single HTML file, no assets, original chiptune "Erika" (traditional march, public domain) via WebAudio.

**Mature: stylized violence** - cartoon pixel blood and gore. No Nazi symbols are depicted.
- Gore ON/OFF switch on the main menu (saved in localStorage, default ON): OFF = no blood, gibs, decals or corpses; enemies poof into dust.
